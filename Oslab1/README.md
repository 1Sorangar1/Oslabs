Ключевые компоненты
1. Config (config.h/cpp)
Назначение: Управление конфигурацией демона

Основные функции:
Singleton-паттерн (единственный экземпляр)
Загрузка и парсинг конфигурационного файла
Поддержка перезагрузки конфигурации по сигналу SIGHUP
Валидация путей к папкам

2. Daemon (daemon.h/cpp)
Назначение: Основная логика демона

Ключевые возможности:

Инициализация и управление:
initialize() - инициализация демона
daemonize() - превращение процесса в демона (двойной fork)
Управление PID-файлом (/tmp/daemon_lab1.pid)
Проверка и завершение предыдущих экземпляров демона

Обработка сигналов:
SIGHUP - перезагрузка конфигурации без перезапуска
SIGTERM - корректное завершение работы

Основной цикл:
run() - главный цикл демона
performTask() - выполнение основной задачи (копирование файлов)
Циклическое выполнение с заданным интервалом

Логика копирования:
clearFolder() - очистка целевой папки перед копированием
copyFiles() - копирование и сортировка файлов
Создание подпапок IMG и OTHERS в папке назначения

3. Main (main.cpp)
Назначение: Точка входа в программу

Логика:
Инициализация системного лога
Чтение пути к конфигурационному файлу (аргумент командной строки или config.txt по умолчанию)
Получение экземпляра демона
Инициализация и запуск демона

Сборка:

chmod +x build.sh
./build.sh

Конфигурация:
файл со строкой формата "/путь/к/папке1 /путь/к/папке2 интервал"

Пример:
/home/user/source /home/user/destination 30
